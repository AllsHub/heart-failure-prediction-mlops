# Heart Failure Prediction MLOps

Author: Aldo Maretra Putra · [LinkedIn](https://linkedin.com/in/aldomrtr)

| Kriteria | Keterangan |
| ----------- | ----------- |
| Dataset | [Heart Failure Prediction Dataset](https://www.kaggle.com/andrewmvd/heart-failure-clinical-data).<br><br>**Deskripsi Dataset:**<br>Dataset ini berisi data klinis yang digunakan untuk memprediksi kematian akibat gagal jantung. Penyakit kardiovaskular (CVDs) adalah penyebab kematian nomor 1 secara global. Deteksi dini melalui *machine learning* sangat krusial.<br><br>**Rincian Data:**<br>• **Jumlah Sampel**: 299 data rekam medis pasien.<br>• **Jumlah Fitur**: 12 Fitur Prediktor + 1 Target (`DEATH_EVENT`).<br>• **Fitur Numerikal**: `age`, `creatinine_phosphokinase`, `ejection_fraction`, `platelets`, `serum_creatinine`, `serum_sodium`, `time`.<br>• **Fitur Kategorikal**: `anaemia`, `diabetes`, `high_blood_pressure`, `sex`, `smoking`. |
| Masalah | Gagal jantung adalah kejadian umum yang disebabkan oleh CVDs. Masalah yang diangkat adalah bagaimana membangun sistem otomatis yang dapat memprediksi risiko kematian pasien secara akurat berdasarkan data klinis, sehingga intervensi medis dapat dilakukan lebih awal. |
| Solusi machine learning | Membangun pipeline **End-to-End TFX** (TensorFlow Extended) yang mencakup seluruh siklus hidup ML: validasi data (*StatisticsGen, SchemaGen, ExampleValidator*), preprocessing (*Transform*), tuning hyperparameter otomatis (*Tuner*), pelatihan model (*Trainer*), evaluasi model (*Evaluator*), dan deployment (*Pusher*). |
| Metode pengolahan | - **Preprocessing**: Menggunakan komponen `Transform` dengan `tensorflow_transform` (TFT).<br>- **Fitur Numerik**: Dinormalisasi menggunakan teknik **Z-Score** (StandardScaler) untuk menyamakan skala distribusi data.<br>- **Fitur Kategorikal**: Dipertahankan dalam format **Integer (int64)** agar kompatibel dengan input model. |
| **Arsitektur Model** | Deep Neural Network (DNN) menggunakan Keras Functional API:<br>1. **Input Layer**: Menerima 12 fitur hasil transformasi.<br>2. **Hidden Layer 1 (Tunable)**: Dense Layer dengan **224 units** (aktivasi ReLU) — *Hasil optimasi Tuner*.<br>3. **Dropout Layer (Tunable)**: Rate **0.4** untuk mencegah overfitting — *Hasil optimasi Tuner*.<br>4. **Hidden Layer 2**: Dense Layer (64 units, aktivasi ReLU).<br>5. **Hidden Layer 3**: Dense Layer (32 units, aktivasi ReLU).<br>6. **Output Layer**: Dense Layer (1 unit, aktivasi Sigmoid) untuk klasifikasi biner.<br>7. **Optimizer**: Adam dengan learning rate **0.01** — *Hasil optimasi Tuner*. |
| Metrik evaluasi | **Binary Accuracy**. Ambang batas (threshold) keberhasilan:<br>- **Absolut**: Akurasi validasi harus > 50% (0.5).<br>- **Relatif**: Model baru harus memiliki metrik yang lebih tinggi daripada model *baseline*. |
| **Performa Model** | Berdasarkan hasil eksperimen terbaik dari komponen Tuner dan validasi akhir oleh Evaluator:<br>• **Status**: **BLESSED** (Model dinyatakan valid untuk di-deploy).<br>• **Akurasi Validasi**: Mencapai **0.8111 (81.11%)**.<br>• Model disimpan dalam format `SavedModel` dengan signature `serving_default` pada direktori *serving_model*. |
| Opsi deployment | Model di-deploy menggunakan **TensorFlow Serving** di dalam container **Docker**. Layanan di-hosting pada platform cloud **Railway** yang terintegrasi dengan GitHub (CI/CD) untuk deployment otomatis setiap kali ada perubahan kode. Akses dilakukan melalui REST API. |
| Web app | [heart-failure-model](https://submission-mlops-production.up.railway.app/v1/models/heart_failure_model/metadata) |
| Monitoring | Sistem monitoring dibangun menggunakan **Prometheus** untuk mengumpulkan metrik (scraping) dari endpoint TensorFlow Serving, dan **Grafana** untuk visualisasi dashboard secara real-time. Metrik utama yang dipantau adalah `:tensorflow:serving:request_count` untuk melihat jumlah request prediksi yang masuk ke server. Terlihat berdasarkan grafik tersebut jika model testing dijalankan maka perintah akan ditembakkan ke server, sehingga grafik pada dashboard Grafana dan Prometheus akan naik dan mendatar setelah server tidak menerima respon selanjutnya. |
