# Heart Failure Prediction Pipeline

Author: Aldo Maretra Putra · [LinkedIn](https://linkedin.com/in/aldomrtr)

| Kriteria | Keterangan |
| ----------- | ----------- |
| Dataset | [Heart Failure Prediction Dataset](https://www.kaggle.com/andrewmvd/heart-failure-clinical-data).<br><br>**Deskripsi Dataset:**<br>Dataset ini berisi data klinis yang digunakan untuk memprediksi kematian akibat gagal jantung. Penyakit kardiovaskular (CVDs) adalah penyebab kematian nomor 1 secara global, merenggut sekitar 17,9 juta nyawa setiap tahun (31% dari seluruh kematian di dunia). Deteksi dini melalui *machine learning* pada pasien berisiko tinggi sangat krusial untuk manajemen medis.<br><br>**Rincian Data:**<br>• **Jumlah Sampel**: 299 data rekam medis pasien.<br>• **Jumlah Fitur**: 12 Fitur Prediktor + 1 Target (`DEATH_EVENT`).<br>• **Jenis Fitur**:<br>&nbsp;&nbsp;1. **Numerikal (7 Fitur)**: `age`, `creatinine_phosphokinase`, `ejection_fraction`, `platelets`, `serum_creatinine`, `serum_sodium`, `time`.<br>&nbsp;&nbsp;2. **Kategorikal (5 Fitur)**: `anaemia`, `diabetes`, `high_blood_pressure`, `sex`, `smoking`. |
| Masalah | Gagal jantung adalah kejadian umum yang disebabkan oleh CVDs. Pasien dengan kondisi ini memerlukan pemantauan ketat. Masalah yang diangkat adalah bagaimana membangun sistem otomatis yang dapat memprediksi risiko kematian pasien secara akurat berdasarkan data klinis, sehingga intervensi medis dapat dilakukan lebih awal. |
| Solusi machine learning | Membangun pipeline **End-to-End TFX** (TensorFlow Extended) yang mencakup seluruh siklus hidup ML: validasi data (*StatisticsGen, SchemaGen, ExampleValidator*), preprocessing (*Transform*), tuning hyperparameter otomatis (*Tuner*), pelatihan model (*Trainer*), evaluasi model (*Evaluator*), dan deployment (*Pusher*). |
| Metode pengolahan | - **Preprocessing**: Menggunakan komponen `Transform` dengan `tensorflow_transform` (TFT).<br>- **Fitur Numerik**: Dinormalisasi menggunakan teknik **Z-Score** (StandardScaler) untuk menyamakan skala distribusi data.<br>- **Fitur Kategorikal**: Dipertahankan dalam format **Integer (int64)** agar kompatibel dengan input model, tanpa melakukan *one-hot encoding* manual karena akan ditangani oleh arsitektur model. |
| Arsitektur model | Deep Neural Network (DNN) menggunakan Keras Functional API:<br>1. **Input Layer**: Menerima 12 fitur hasil transformasi.<br>2. **Hidden Layer 1**: Dense Layer dengan **64 units** (aktivasi ReLU) — *Optimized by Tuner*.<br>3. **Dropout Layer**: Rate **0.2** untuk mencegah overfitting — *Optimized by Tuner*.<br>4. **Hidden Layer 2**: Dense Layer (64 units, aktivasi ReLU).<br>5. **Hidden Layer 3**: Dense Layer (32 units, aktivasi ReLU).<br>6. **Output Layer**: Dense Layer (1 unit, aktivasi Sigmoid) untuk klasifikasi biner.<br>7. **Optimizer**: Adam dengan learning rate **0.01** — *Optimized by Tuner*. |
| Metrik evaluasi | **Binary Accuracy**. Ambang batas (threshold) keberhasilan:<br>- **Absolut**: Akurasi validasi harus > 50% (0.5).<br>- **Relatif**: Model baru harus memiliki metrik yang lebih tinggi daripada model *baseline* (model sebelumnya yang sudah berstatus "Blessed"). |
| Performa model | Berdasarkan hasil eksperimen terbaik dari komponen Tuner dan validasi akhir oleh Evaluator:<br>- **Status**: **BLESSED** (Model dinyatakan valid dan disetujui untuk deployment).<br>- **Akurasi Validasi**: Mencapai **0.8222 (82.22%)**.<br>- Model berhasil melampaui baseline dan threshold batas bawah, menunjukkan kemampuan generalisasi yang baik pada data yang belum pernah dilihat sebelumnya.<br>- Model disimpan dalam format `SavedModel` dengan signature `serving_default` pada direktori *serving_model*. |
